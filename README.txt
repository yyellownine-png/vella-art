COTTEE WEBSITE — DEMO

Files:
- index.html — the complete responsive website (HTML, CSS and JavaScript in one file)

Publish with GitHub Pages:
1. Open the repository: https://github.com/yyellownine-png/cottee-website
2. Replace the repository's existing index.html with this index.html (upload to the repository root).
3. Commit changes.
4. In Settings > Pages, set Deploy from a branch, branch main, folder /(root).
5. Wait for GitHub Pages to publish, then open https://yyellownine-png.github.io/cottee-website/

IMPORTANT BEFORE OFFICIAL USE:
- Menu items, bakery availability, prices and photos are illustrative and must be confirmed/replaced by Cottee's owner.
- Locations and social links are based on publicly available information; confirm before representing the site as official.
- The review form is a local demo: reviews are stored in the visitor's browser only and are not shared with other visitors. A real public review system needs a database or an external form/review service.
- This package does not include a custom domain or backend.
